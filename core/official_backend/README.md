# Official Core Backend

[中文](#中文) | [English](#english)

## 中文

此可选后端仅作为本地私有验证的适配边界。仓库不得包含 Live2D 官方 Cubism Core 二进制文件、官方 SDK 文件，或嵌入这些文件后生成的可再分发软件包。

未来的构建应通过 CMake 配置接受用户提供的 SDK 路径。

## English

This optional backend is only an adapter boundary for local private validation. The repository must not contain Live2D official Cubism Core binaries, official SDK files, or generated redistributable packages that embed them.

Future builds should accept a user-supplied SDK path through CMake configuration.
