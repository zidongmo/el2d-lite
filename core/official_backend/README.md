# Official Core Backend

[中文](#中文) | [English](#english)

## 中文

此可选后端仅作为本地私有验证的适配边界。根据 EL2D Lite 的仓库发布政策，仓库不得包含 Live2D 官方 Cubism Core 二进制文件、官方 SDK 文件，或嵌入这些文件的分发产物。

这是 EL2D Lite 仓库的发布政策；它不判断第三方许可是否允许外部分发，也不授予此类许可。

未来的构建应通过 CMake 配置接受用户提供的 SDK 路径。

## English

This optional backend is only an adapter boundary for local private validation. Under the EL2D Lite repository publication policy, the repository must not contain official Live2D Cubism Core binaries, official SDK files, or distribution artifacts that embed them.

This is a publication policy for the EL2D Lite repository; it does not determine whether third-party licenses permit external distribution, and it grants no such permission.

Future builds should accept a user-supplied SDK path through CMake configuration.
